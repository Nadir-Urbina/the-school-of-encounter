Project Description:

You are building a web app for online learning called "The School of Encounter", this is a place where people can buy individual courses, the courses are primarily focused on the teachings of the Bible, leadership, intercession, deliverance, inner healing, and other related topics.

Admins of this app also login to the CMS (sanity) to create courses and manage students, and enrollments.

Instructors can login to the app and have access to a customized dashboard where they can track number of students enrolled in their course, and monthly revenue generated from the course.


Tech Stack:

- Next.js
- Tailwind CSS
- Shadcn UI
- React
- Sanity
- Stripe
- Firebase
- Vercel
- Github
- Resend


Specific Requirements:

- User authentication
- Students should have the ability to track their progress
- Students have the ability to purchase courses
- Students can send messages to instructors from their dashboard
- Students receive a completion certificate after completing a course
- Students can manage their profile information from their dashboard
- Instructors can manage their own profile information from their dashboard
- Instructors can track number of students enrolled in their course
- Instructors can track monthly revenue generated from their course
- Admins can use Sanity to create courses, and manage students, and enrollments
- Courses are bought as a one time payment
- Courses have a name, description, and price
- Courses are primarily video based
- Some courses may have quizzes
- Admin can create instructors from sanity
- Once a student purchases a course, sanity should update the student's profile to add the enrollment of the given course
- Instructors should be able to see the list of students enrolled in their course
- Each course should have a Q&A section
- Students can request help regarding the platform by using a "support" button to send a message to the admin
- This platform should be mobile responsive, in fact it should be optimized for computers, tablets and mobile devices
- This platform should have a modern but yet simple UI/UX
- This platform should have a nice animation and transition
- This platform should have a nice color scheme
- This platform should have a nice typography
- The information of students will be private and only their email addresses and full names will be visible to the instructors
- All notifications for students and instructors should be sent via email
- Each course should have a preview page where the users can see the course content and enroll/purchase the course if they decide to do so
- When students add a questions in the Q&A section, the instructor should receive an email notification
- Q&A questions cannot include innapropiate language
- No limits in enrollment, students can enroll in as many courses as they want, and as many students can enroll in a course as they want
- One student can enroll/purchase a course only once since the payment model is a one time payment
- Once a course has been purchased, the student should have access to the course content permanently
